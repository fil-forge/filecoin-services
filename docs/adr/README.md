# Architecture decision records

Decisions about how this repository and FF's FWSS deployment differ from upstream FilOzone/filecoin-services, and why.

| ADR | Title | Status | Date |
|---|---|---|---|
| [0001](0001-fwss-fork.md) | Run a separate FWSS deployment built from upstream code | Accepted | 2026-10-07 |

## Format

One file per decision, named `NNNN-short-title.md` and numbered in order. Each record states its status, date and decision first, then the context, the decision in detail, its consequences and the alternatives considered. A superseded record keeps its text, changes its status to "Superseded by NNNN" and links to the record that replaces it.

Feature designs referenced by these records live in [`../design/`](../design/).
